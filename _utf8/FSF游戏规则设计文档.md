# 五、游戏时间系统

## 5.1 核心时间规则

游戏使用：

# 「持续世界时间系统」

正式时间比例统一为：

```text
1现实分钟 = 1游戏小时

24现实分钟 = 24游戏小时

24游戏小时 = 1游戏日
```

因此：

```text
1游戏日 = 24现实分钟
```

原规则中的这一时间换算继续保留。

---

# 六、退出游戏规则

玩家退出游戏后：

**游戏程序关闭，但农场世界并非永久暂停。**

退出时记录：

```text
logoutRealTime
currentWorldTime
当前天气
当前事件
所有作物状态
所有玩家资源
```

再次启动游戏时：

```text
当前真实时间
-
logoutRealTime
=
实际离线时长
```

系统根据实际离线时长进行离线模拟。

---

# 七、离线模拟保护机制

为避免玩家退出数小时后返回，农场已经自动经历几十个游戏日，正式版本设置：

# 单次离线最大结算3游戏日

即：

```text
最大离线模拟时间
=
72游戏小时
=
72现实分钟
```

例如：

玩家离开20现实分钟：

```text
模拟20游戏小时
```

玩家离开60现实分钟：

```text
模拟60游戏小时
```

玩家离开8现实小时：

```text
最多模拟72游戏小时
=
3游戏日
```

超出部分不再继续结算。

设计目的：

- 保留“离开后农场继续发生故事”的特色；
- 避免玩家睡一觉回来作物全部枯死；
- 避免离线事件一次性刷几十条；
- 控制经济膨胀；
- 保证玩家仍然需要回到游戏作出决策。

离线世界、离线天气、事件日志与生命记忆仍然是项目的重要特色系统。

# 十二、土地状态

```java
enum SoilState {

    EMPTY,

    TILLED,

    PLANTED,

    LOCKED

}
```

---

## 12.1 EMPTY

普通空地。

不可直接播种。

操作：

```text
EMPTY

↓ 开垦

TILLED
```

开垦消耗：

```text
5金币
```

原设计的5金币开垦规则继续保留。

---

## 12.2 TILLED

已开垦土地。

允许：

```text
播种
```

不允许：

```text
浇水
施肥
收获
```

因为该状态不存在Crop。

---

## 12.3 PLANTED

土地中存在Crop。

根据Crop当前GrowthStage决定：

- 是否可以浇水；
- 是否可以施肥；
- 是否可以收获；
- 是否存在枯萎风险。

---

## 12.4 LOCKED

尚未解锁土地。

不可：

- 开垦；
- 播种；
- 放置装饰。

后期通过金币进行土地扩张。

土地解锁价格属于平衡配置数据，不硬编码在核心规则中。

# 十六、成长阶段

作物成长进度：

```text
0% ～ 20%
SEED

20% ～ 50%
SPROUT

50% ～ 100%
GROWING

≥100%
MATURE
```

---

## 16.1 SEED

种子阶段。

规则：

- 不可收获；
- 不可施肥；
- 不参与枯萎判定；
- 不主动计算干旱死亡风险。

种子阶段免疫规则仅根据：

```text
stage == SEED
```

判断。

不再使用“固定24小时免疫”的冲突规则。

---

## 16.2 SPROUT

幼苗阶段。

允许：

- 主动浇水；
- 施肥。

开始：

- 接受天气影响；
- 接受装饰Buff；
- 接受事件影响；
- 参与枯萎检测。

---

## 16.3 GROWING

成长阶段。

接受所有成长、品质、天气和事件影响。

---

## 16.4 MATURE

成熟阶段。

玩家可以：

```text
收获
```

成熟作物仍然可能因为长期极端干旱枯萎。

因此成熟不等于绝对安全。

---

## 16.5 WITHERED

枯萎。

规则：

- 无法收获；
- 无法出售；
- 无金币；
- 无肥料奖励；
- 不完成图鉴；
- 枯萎经历写入CropMemory；
- 必须玩家主动铲除。

铲除免费。

铲除后：

```text
SoilState = TILLED
Crop = null
```

---

# 十七、成长进度计算

每株作物拥有：

```text
growthProgress
```

范围：

```text
0 ～ 100
```

基础公式：

```text
GrowthDelta
=
基础每日成长进度
×
时间比例
×
WeatherRate
×
DecorationRate
×
OperationRate
×
EventRate
```

其中：

```text
基础每日成长进度
=
100 ÷ 基础成长天数
```

因此：

小麦：

```text
100 ÷ 2
=
50% / 游戏日
```

玉米：

```text
33.333% / 游戏日
```

胡萝卜：

```text
25% / 游戏日
```

---

# 十八、非整日成长

成长不是只能每天结算一次。

例如过去：

```text
6游戏小时
```

则：

```text
时间比例
=
6 ÷ 24
=
0.25游戏日
```

系统按照0.25游戏日计算成长。

因此在线期间作物可以在一天中途成熟。

枯萎必须同时满足：

```text
① 作物不处于SEED

② 当日存在干旱风险

③ 没有有效补水

```

# 二十九、连续干旱定义

正确规则：

```text
如果：

当日天气 == DROUGHT
且
当天没有有效补水

则：

droughtStreak +1
```

否则：

```text
droughtStreak = 0
```

因此：

```text
干旱
晴天
干旱
```

不是连续2天干旱。

中间出现任何：

- 晴天；
- 雨天；
- 绿雨；
- 主动有效浇水；

都会终止连续干旱。

# 三十一、石灯笼抗性

D06石灯笼：

```text
最终枯萎概率 ×0.7
```

例如：

```text

70% → 49%

100% → 70%
```

注意：

> 石灯笼只降低枯萎概率。

不会改变：

```text

```

因此不再使用含义模糊的：

```text
“干旱影响-30%”
```

# 九十四、设计原则总结

整个游戏必须遵守以下原则：

## 原则1

玩家操作必须比纯随机更重要。

## 原则2

天气负责制造经营情境。

## 原则3

装饰必须影响经营，而不仅是外观。

## 原则4

高品质必须能够通过策略培养。

## 原则5

传说必须有独特成长故事。

## 原则6

离线世界必须产生内容，但不能惩罚过重。

## 原则7

失败应产生新的决策，而不是单纯浪费时间。

## 原则8

全收集必须存在明确终点。

## 原则9

正常首次玩家目标毕业时间为6～8小时。

## 原则10

所有规则必须能被程序解释、测试和复现。

# 九十六、最终统一结论

《田野物语 · 三韵集》的最终核心体验为：

```text
种植
+
观察世界
+
主动干预
+
承担风险
+
培养品质
+
创造故事
+
完成收藏
```

玩家不是单纯等待计时器。

天气不是纯粹随机惩罚。

装饰不是只有视觉价值。

传说不是单纯高分。

离线不是简单挂机收益。

所有系统共同服务于：

# 「每一株作物都有经历，每一次经营都有选择。」

+
